# Skill Creator（旧版 — skill-builder に移行済み）

このスキルは **`skill-builder`** に統合されました。

スキルの新規作成・既存スキルの更新・品質改善は、すべて **`skill-builder`** を使ってください。
旧 `skill-creator` が持っていた資産（設計パターン・ワークフロー・出力テンプレート・テスト/トラブルシューティングのリファレンス、`package_skill.py`）は `skill-builder` に移植済みで、さらに高品質設計（progressive disclosure、What/Why/Deliverables、アンチパターン防止、フォワードテスト）が加わっています。

→ **`skill-builder` を呼び出してください。**
